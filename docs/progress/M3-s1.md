Decisions (deviations from M3-pan.md):
- Flags live on the existing `.phase` channel (no new `.flags` channel): `StateChannel` unchanged.
- `endDrag` negates tracker/fallback velocity: the tracker is fed FINGER locations, offset velocity = -finger velocity. Part b must feed `startLocation + translation` and pass `DragGesture.Value.velocity` raw.
- `ReleaseRequest` gained `lock`, `caughtAt`, `caughtVelocity`, `zeroVelocity`; cancelled => `liftTime = .nan` (endDrag uses `state.now()`). `PanEnvironment` gained `interruptedVelocity` (read at recognition, after the catch's interrupt()). `ReleaseSettings` is the release half of `PanSettings` (part b builds both).
- `beginDeceleration` does NOT write `targetOffset` (design said end position): target stays = presentation, so TransformHost never shows a one-frame jump to the end. Settles with pixel snap using `metrics.displayScale` (or the passed scale).
- `interrupt()` fires `didEndDecelerating` for a stopped deceleration, but not `didEndScrollingAnimation` for an interrupted animation (UIKit parity; design §6 said both).
- `.ignored` sequences end with no effects (not `.endSequence`): a container-owned sequence leaves flags/phase untouched. Touch-down while disabled or touchCount >= 2 => `.ignored`.
- `touchesEnded` while dragging is ignored; the lift is `dragEnded`/`cancelled`.
- Bounds clamping applies to gesture offsets only (PanSession); programmatic writes are unchanged.
