4. The aligned item is remembered by id, not by a numeric index; the resize realigns unanimated at rest after the close (and during the 3-turn settle window when the frame arrives late), so a mid-transition frame still follows the centre rule (documented abruptness, as for paging).
5. `layoutEnabled` counts every disabled layout (tokens), so one disabled layout among several disables view alignment; ids are not scoped to their layout (Q3 gap).
